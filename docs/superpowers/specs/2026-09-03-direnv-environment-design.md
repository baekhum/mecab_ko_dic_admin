# direnv 로컬 환경 설계

- **상태:** Approved
- **날짜:** 2026-09-03
- **대상:** 로컬 개발 셸

## 목표

프로젝트 디렉터리에 진입할 때 direnv가 로컬 `.env` 변수를 불러오고, uv가 관리하는 기존 `.venv`를 활성 Python 환경으로 사용하도록 한다.

## 동작

루트 `.envrc`는 다음 순서로 동작한다.

1. `.env`가 존재하면 해당 변수를 내보낸다. 파일이 없으면 오류 없이 계속한다.
2. 루트 `.venv`가 존재하면 `VIRTUAL_ENV`를 해당 경로로 설정하고 `.venv/bin`을 `PATH` 앞에 추가한다.
3. `.venv`가 없으면 환경을 자동 생성하지 않고 `uv sync` 실행 안내를 출력한다.

## 제약

- direnv가 별도 Python 가상환경을 만들지 않는다.
- 디렉터리 진입 시 `uv sync`나 패키지 설치를 자동 실행하지 않는다.
- `.env` 및 `.venv`는 버전 관리 대상에 포함하지 않는다.
- `.envrc`에는 비밀값을 직접 기록하지 않는다.

## 검증

다음 조건을 확인한다.

- `direnv allow .`가 성공한다.
- `direnv exec .`에서 `VIRTUAL_ENV`가 저장소의 `.venv`를 가리킨다.
- `direnv exec .`에서 `python`이 `.venv/bin/python`으로 해석된다.
- `.env`의 비밀값 자체를 출력하지 않고, 대표 변수의 설정 여부만 확인한다.
